# 디자인 시스템 — 함께읽기

기준: Apple 웹 디자인 분석(DESIGN.md)을 **모바일 독서 앱**에 맞게 번안. Figma 원본:
[함께읽기 (Saipr) — MVP Screens](https://www.figma.com/design/mp2nKNmBdJ7Dg2rc2p9rht)

## 원칙

1. **책이 주인공.** UI 크롬은 물러난다. 장식 그라디언트·카드 그림자 없음.
2. **단일 액센트.** 모든 상호작용 요소는 Action Blue `#0066cc` 하나. 예외는 카카오 로그인·초대 버튼(`#FEE500`, 브랜드 가이드 준수) 단 하나.
3. **표면 교대가 구분선.** 파치먼트(`#f5f5f7`) ↔ 흰색 ↔ 다크 타일(`#272729`). 경쟁 화면(레이스)만 다크 캔버스 — 몰입 전환 신호.
4. **스포일러는 잠금 칩으로.** 잠긴 반응은 내용 대신 개수만, 다크 필 칩으로 표시.

## 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `primary` | `#0066cc` | 버튼, 링크, 진행률 바, 활성 탭 |
| `primary-on-dark` | `#2997ff` | 다크 타일 위 강조·진행률 |
| `ink` | `#1d1d1f` | 본문·제목, "나"의 진행률 바 |
| `muted` | `#7a7a7a` | 보조 텍스트, 비활성 탭 |
| `canvas` / `parchment` | `#ffffff` / `#f5f5f7` | 화면 배경 교대 |
| `tile-dark` / `tile-dark-2` / `tile-dark-3` | `#272729` / `#2a2a2c` / `#252527` | 이어읽기 카드, 레이스 화면 |
| `hairline` | `#e0e0e0` | 카드 1px 테두리, 진행률 트랙 |
| `kakao` | `#FEE500` | 카카오 버튼 전용 |

**반경:** 칩·버튼·검색 `9999px` / 카드 `18px` / 보조 박스 `11px` / 표지 `8px`
**간격:** 8px 기반 — 화면 좌우 24px, 섹션 간 20–24px, 카드 내부 18–24px

## 타이포그래피

한글 지원을 위해 SF Pro 대신 **Noto Sans KR**(웹: `Pretendard` → `Noto Sans KR` → `system-ui`) 사용. 웨이트 사다리는 400 / 500 / 700 (Noto에 600 없음 → 700이 Apple 600 역할).

| 역할 | 크기 / 웨이트 | 자간 |
|---|---|---|
| 화면 제목 | 34 / 700 | -0.6px |
| 카드 제목 | 28 / 700 | -0.5px |
| 섹션 제목 | 21 / 700 | -0.2px |
| 본문 | 17 / 400 | -0.3px |
| **리더 본문** | 17 / 400, 행간 170% | -0.3px (장문 독서용 예외) |
| 캡션 | 13–14 / 400 | 0 |
| 탭 라벨 | 11 / 400 | 0 |

## 컴포넌트 (Figma 노드 이름 기준)

- `btn/*` — 풀 필 버튼. 눌림 상태 `scale(0.95)`.
- `card/continue` — 다크 타일 이어읽기 카드: 책 제목, 출처·모드, 진행률 바(`primary-on-dark`), CTA.
- `card/room` — 흰 카드 + hairline. 방 이름, 모드·기한, 겹친 아바타(-8px), 최신 활동 한 줄(파랑).
- `search-input` — 파치먼트 필 입력.
- `result-row` — 표지(60×84) + 제목 + 출처 + 모드 배지(`전문 읽기 가능` 파랑 / `진행률 기록` 회색).
- `reaction-overlay` — 문단 아래 파치먼트 박스: 아바타 스택 + 반응 수 + 대표 한줄평.
- `presence` — "○○님이 지금 이 문단을 읽고 있어요" (동기 모드).
- `spoiler-guard` — 하단 다크 필 칩 "잠김 · 앞에서 N개의 반응이 기다리고 있어요".
- `scoreboard` / `tug-bar` — 레이스 점수판과 줄다리기 바.
- `rank-row` — 리그 순위 행. 우리 팀은 파랑 필, 승급선은 `promotion-line`.
- `tab-bar` — 홈 / 검색 / 읽기방 / 리그. 아이콘+라벨 필수.
